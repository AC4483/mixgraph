# Contributing to Mixgraph

Thanks for helping out! Mixgraph is one HTML file with no build step, so getting started takes a minute.

## Run it locally

1. Fork and clone the repo.
2. Open `index.html` in your browser. That's it.

Your test library is saved in your browser's localStorage, so it won't touch anyone else's data.

## Make a change

1. Create a branch: `git checkout -b my-change`
2. Edit `index.html`. The CSS is at the top, the app logic is in the `<script>` at the bottom.
3. Check it in a desktop browser and at phone width (about 400px), in both light and dark mode.
4. Make sure the browser console shows no errors.
5. Open a pull request describing what you changed and why. A screenshot helps.

## Good places to start

Look for issues labeled [`good first issue`](https://github.com/AC4483/mixgraph/labels/good%20first%20issue).

## Questions

Ask in [Discussions](https://github.com/AC4483/mixgraph/discussions). Use Issues for bugs and feature requests.
